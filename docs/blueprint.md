# **App Name**: GeoAnalyst Demo - Fase 1

## Core Features:

- Mission Briefing (Biomas - Caatinga Demo): Apresenta o objetivo específico de identificar o bioma Caatinga, juntamente com uma imagem de alta resolução de uma paisagem seca com cactos, como principal pista visual para esta fase de demonstração.
- Interactive Keyword Terminal: Fornece uma interface de linha de comando para o jogador digitar palavras-chave relevantes para a imagem exibida, como 'cacto', 'seca', 'sol', 'semiárido'.
- Dynamic Clue Tagging & Scoring: Processa as palavras-chave válidas inseridas pelo jogador para a fase Caatinga, exibindo-as como tags interativas e calculando imediatamente os pontos com base em sua especificidade (ex: 'sol' -> 5 pts, 'seca' -> 10 pts, 'semiárido' -> 30 pts).
- Biome Revelation (Caatinga): Permite ao jogador enviar sua dedução. Após o envio, revela 'Bioma identificado: Caatinga' como a resposta correta para esta fase de demonstração.
- AI-Powered Educational Debrief (Caatinga): Uma ferramenta AI gera e exibe um resumo educacional conciso, no estilo ENEM, especificamente para o bioma Caatinga: 'A Caatinga é o único bioma exclusivamente brasileiro e apresenta plantas adaptadas à escassez de água.'
- Demo Scoring Summary: Exibe a pontuação total alcançada para a fase Caatinga, com base nos pontos acumulados das pistas identificadas, fornecendo feedback imediato sobre o desempenho.

## Style Guidelines:

- Scheme: Dark mode, evoking a professional scientific terminal. Primary interactive elements: #6633CC (a deep violet), signifying investigation and insight. Background: #1C1A22 (a very dark purplish-gray), providing a subdued backdrop. Accent for highlights and active states: #4AA1FA (a clear, bright blue), indicating interactivity.
- All text: 'Space Grotesk' (sans-serif), for a precise, techy, and analytical feel that matches the scientific investigation theme.
- Use minimalist, line-art, or outline icons to maintain the clean, functional aesthetic of a digital terminal interface.
- Adopt a structured, clear layout reminiscent of a command-line interface or a data analyst's dashboard, with distinct panels for images, input, and feedback.
- Implement subtle animations like a soft 'typewriter' effect for text in the terminal and gentle fade-ins for revealed information, enhancing the interactive investigation feel without distraction.
